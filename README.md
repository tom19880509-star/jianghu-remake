# 江湖重绘 · Jianghu Remake

**项目发起、设计与制作：Tom（[tom19880509-star](https://github.com/tom19880509-star)）。**

这是 Tom 正在制作的武侠浏览器游戏的第一批原创独立模块，免费提供源码。开发中使用了 Codex 和 Claude 辅助工具。

## 当前公开范围

本包包含从实际游戏源码提取的十五个独立模块：点击寻路、手机摇杆、战斗格子与屏幕坐标转换、人物遮挡判断、横屏引导、出招范围文字、住宿存档交互、开局分配能力点、行走插值、兵器适配、物品分级及程序绘制的兵器图。

**这还不是下载后即可运行的完整游戏，也不是原版《金庸群侠传》源码的重新授权。** 原游戏运行脚本、剧情对白、地图／人物底表、旧贴图、音乐、玩家存档及内部协作记录均未包含。完整运行版仍依赖这些尚未厘清授权的外部内容；后续只增加权利明确的部分。

## 使用和验证

需要 Node.js 20.10 或以上。本包没有第三方运行依赖。

```sh
npm test
```

例如在自己的模块中导入：

```js
import { pathfind } from './navigation.js';
import { gameViewport } from './viewport.js';
import { battleSkillText } from './battle-preview-text.js';
```

部分界面模块需浏览器 DOM 和游戏提供的数据／回调；不是完整游戏启动器。现有检查覆盖遮挡、抬高门槛的格子投影、摇杆遇墙及可达路径，不能视为完整游戏、手机真机或所有剧情已经验收。
